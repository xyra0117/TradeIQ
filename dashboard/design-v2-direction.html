界面重设计 · 方向稿 · 2026.10

把「能用」变成「想每天盯着看」

现有页面不是配色不好看，而是没有设计系统—— 1204 处内联样式、约 20 种圆角、14 种字号、颜色散落硬编码，容器还写死 1400px 上限。 这次重做的核心动作是先立 token 层，再把内联样式收敛回 class， 而不是在现有 CSS 上打补丁。功能结构、选股逻辑、数据口径一律不动。

范围：仅桌面端 原页面零改动，另开预览版 8 个页面全部保留 Tab 收敛为 4 个一级域 主从两栏替代弹窗 白天 / 夜间双主题
01

设计方向

方向代号 Professional Dark Desk —— 用层级表面 + 克制描边表达空间关系，取代现有的发光与渐变堆叠。 界面应该像一台安静的专业设备：信息密度高，但不吵。

主轴

层级靠明度，不靠发光

4 级表面（surface-0→3）+ 3 级描边构成全部空间关系。卡片不再有渐变顶条动画和 hover 位移，只在 hover 时描边加深一档。

现状：霓虹 cyan 高亮 · 顶部渐变条 · translateY 位移 · 蓝红网格纹理

主轴

强调色只做三件事

品牌主色严格限定用于「当前选中态」「主操作按钮」「焦点环」。涨跌色只出现在数值和徽标上，不做边框和背景填充。

现状：同一个 cyan 同时当链接色 / 选中色 / 下划线 / 排序色

主轴

数字是主角

所有数值走等宽字体 + tabular-nums，右对齐；中文标签回归系统 UI 字体（现状给中文套了 JetBrains Mono，靠 fallback 硬撑）。

现状：中文标签套等宽字体 · 字号 14 档并存

02

色彩体系

四个层级共 13 个 token，覆盖页面全部着色需求。任意裸 hex 都应被 token 取代—— 验收时会用 grep -oE '#[0-9a-fA-F]{3,6}' 核查残留。

白天模式 · 不是把背景反过来

当前 —

涨跌色压深

红 — / 绿 —。 暗色下 #ff5a68 在白底只有约 3:1，撑不住表格小字，白天版整体压深一档。

描边换层级

暗色靠明度差分层，白底明度差不够，描边整体加深，并启用一层极淡投影托住卡片。

表面差拉大

暗色相邻表面差约 4%，白天拉到约 6%（— → —），否则白底一片糊。

主色同步降饱和

三个品牌色各配一个白天版（—），切换主题时自动跟换，不会拿亮色去压白底。

03

字体与字阶

三种角色：UI 文本用系统中文字体（不再下载 webfont，首屏更快、字形更原生）、 等宽数字只用于数值与代码、微标签统一大写字距。 字阶从现状的 14 档收到 7 档。
