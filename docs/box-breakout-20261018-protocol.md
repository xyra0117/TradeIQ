# 箱体突破形态研究协议

日期：2026-10-18。用户未指定年份，本轮按2026年核对11个股票/日期。目标是把用户举例的“箱体整理后突破”转成可核验的筛选条件，不修改现有策略。

## 样本与信息边界

中润光学03-02、广钢气体06-22、斯莱克06-22、昆船智能09-22、向日葵10-09、晶雪节能10-08、国力电子06-30、杰恩股份03-23、善水科技09-28、近岸蛋白08-07、澳弘电子09-10，共11例、10个指定日期。

只读`backend/market_data.db`，SQLite使用`mode=ro`、`query_only`及读事务，不导入`app.py`。研究输入截止信号日，不用未来涨幅挑选参数。日线必须按本地交易日历连续；OHLC、成交量须有效，收盘推算涨跌幅与记录值误差不得超过0.15个百分点。未复权价格断点不跨越计算可信长窗口，保留原值供审计但不当成已核验指标。数据不完整保留原因，不补零。

## 预先比较的形态维度

1. 固定20、30、40、60、90、120交易日窗口，均为信号日之前的交易日。箱顶分别采用最高价和最高收盘价；箱底分别保留最低价和最低收盘价。两种箱顶不混称。
2. 箱体宽度、前后5日均价变化、箱体内首尾涨幅、触顶位置、最近5日与前段量能、突破前均线偏离。较窄窗口也可能是上升趋势，不能仅凭宽度认定横盘。
3. 信号日收盘是否突破、突破幅度、当日最高是否突破、昨日是否已经突破昨日的同周期箱顶；另查近期已突破的情况，区分首次启动与延续上涨。
4. 当日涨幅、当日量/此前5日与20日均量、收盘在当日高低区间的位置、成交额；补充MA排列、连续同源资金与上证/涨跌家数。资金缺失不替换来源。
5. 各合理参数组合对11例的覆盖及漏选原因，并在这些日期全市场进行同口径筛选；其他入选股票为未标注候选，不自动认定是假突破或失败股票。允许结论为多个子形态，不能为了全覆盖取消形态约束。

阈值从上述维度的样本描述与覆盖/宽泛程度比较中提出，属于已查看样本的探索结果。没有随机正负样本，也没有未触碰的形态验证集，因此不报告胜率，不声称参数最优或收益有效。

## 交付与核验

输出一份中文报告、逐例CSV、完整JSON和截至信号日的价格/成交量图。推荐条件给出单位、严格/包含边界、当前自定义公式是否支持，以及每例覆盖情况。说明尚缺复权因子、历史资金或其他数据及影响。

收盘、全天成交量和当日最终资金仅在收盘后确认；本研究不能证明当天盘中已能选出。测试覆盖排除当日/未来、首次突破、边界、价格断点和缺日；从原始SQL独立抽查样本。研究结束不改现有筛选参数。
