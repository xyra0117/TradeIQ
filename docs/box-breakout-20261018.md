# 11例“箱体突破”研究

开始于2026-10-18，完成于2026-10-19。日期按2026年解释。全部使用本地数据库；没有更改现有选股条件。

## 先说结论

这组股票最一致的特征是：**短期整理之后，成交量放大，收盘价突破近20个交易日的最高收盘价，且收盘没有大幅回落。**

它们不是完全相同的标准横盘箱体：部分是宽幅整理，部分是下跌后的修复，部分在指定日期之前已经开始突破。尤其不能把“突破最高收盘价”和“突破包含上影线的最高价”混为一谈。

建议先做一个“箱体突破观察池”，用下面6项筛选，再把首次突破、已越过上影线高点等作为分类标签。这样保留你想找的类型，也能知道哪些更接近严格的箱体突破。

这6项在指定日期覆盖**11/11例**。同日全市场经数据核验后，共选出**863条日期×股票记录、804只不同股票**，10个日期平均**86.3只/日**，范围21～186只。它是一个待进一步观察的池子，不能精准识别只有这11只；尚未验证未来收益或假突破率。

## 可以怎么设置

所有“此前N日”都不包含筛选当天，按本地交易日历计算。所有条件同时满足。

| 条件 | 建议初始值 | 大白话解释 |
|---|---|---|
| 整理周期 | 前20个交易日 | 先看大约一个月的整理，不要求一定横盘三个月 |
| 整理范围 | 前20日最高价÷最低价−1 ≤35% | 整理期间允许波动；不是每天涨跌35%，也不是收盘涨幅35% |
| 避免一路单边上涨/下跌 | 最后5日平均收盘价相对最初5日的变化，绝对值≤10% | 箱体两头的平均价格不能差太多；这是简化横盘判断，不等于自动识别完整箱体 |
| 收盘突破 | 当日收盘超过此前20日最高收盘价至少1% | 跨过近一个月的收盘压力，避免只高出一两分钱 |
| 放量 | 当日量÷此前5日均量 ≥1.2倍 | 有资金成交响应；先不要硬要求翻倍 |
| 当日涨幅 | ≥2% | 保留澳弘电子这种温和突破 |
| 收盘位置 | （收盘−最低）÷（最高−最低）≥60% | 收盘处在当天振幅上方40%的区域，排除冲高后回落较多的走势 |

上表的“周期”是参数，其余6行是独立条件。数值是从这11个已查看样本提出的研究初始值，不是经过独立样本验证的最优参数。高低范围35%对部分股票仍然偏宽，因此只能称观察池。

### 三种日期差异必须分清

1. **斯莱克、杰恩股份：突破的是收盘压力，尚未完全越过上影线高点。**斯莱克当日收17.88元，前20日最高价17.90元；杰恩收盘仍比前20日最高价低0.17%。硬要求收盘严格超过最高价会漏掉这两例。
2. **晶雪节能、国力电子、澳弘电子：不是首次突破各自前20日最高收盘价。**晶雪在09-30、国力在06-29、澳弘在09-09已分别超过其当时前20日最高收盘价1.12%、3.47%、3.17%。指定日期可以作为继续放量确认日，但不能按这一固定口径称首次突破日。这不代表更长周期箱体也早已突破。
3. **较长箱体不等于短箱体。**杰恩03-23仍比前40日最高收盘价低4.50%，近岸08-07仍比前60日最高收盘价低8.18%。它们是短区间突破/修复，并未跨过所有旧高。昆船的前40日高低范围仅11.23%，更接近清晰的窄箱体；广钢、善水的前20日高低范围超过31%，属于更宽的整理。

保持同样阈值，只把周期20改为30/40/60日，样本覆盖分别为11/7/5/2例，候选日均86.3/47.3/29.5/12.5只。更长周期会改变形态，并且善水、澳弘的60日价格窗口存在参考断点，不能把数据无法核验当作条件不满足。

## 原来低吸/追高的哪些条件不适合直接搬过来

- **当日下跌、量比小于1.2**：这11例恰好都是上涨放量，与这两个低吸条件相反。
- **必须上证上涨或必须上证下跌**：7例发生在上证上涨日、4例在下跌日。杰恩当日上证−3.63%，善水−1.67%；强制大盘上涨会漏掉它们。
- **严格均线多头**：斯莱克、向日葵、近岸蛋白、澳弘电子原始均线不满足完整排列；善水60日还跨参考价断点。加上严格排列和60日有效性后，仅6/11例通过。箱体刚启动时，长期均线未必已排好。
- **资金全红**：东方财富数据显示，斯莱克5日主力为负，善水、澳弘20日主力为负，国力当日主力为负；另有历史窗口缺失。资金可以展示辅助判断，不能说是这11例的共同硬条件。
- **涨幅>5%、放量翻倍、均线必须非常粘合**：都会遗漏具体例子。没有证据证明这些更严格条件能提高未来收益；本轮只比较形态覆盖和名单规模。

## 本地缺什么，影响什么

1. **11例目标日及此前120个交易日的121根日线、成交量和成交额齐全；同窗上证和盘面数据齐全。**足够做本轮短期形态研究。
2. **缺复权因子/可核验的历史除权记录。**发现中润2025-10-23、善水2026-07-14、澳弘2026-07-01的收盘推算涨跌幅与记录值偏差超过0.15个百分点，原因可能是除权除息或数据错误，不能直接断定。三例的前40日窗口均没有这些断点；善水、澳弘60日及更长窗口、中润90/120日窗口不能作为已核验长箱体。优先补复权因子或完整复权日线。
3. **东财资金早期缺失。**全库起于2026-04-09，中润/杰恩3月无法核验；国力窗口缺06-29，近岸窗口缺07-31。可补历史资金，但不是当前价格形态研究的必需条件。
4. **同花顺资金覆盖更短。**起于08-21，本轮6例无法核验。其余5例中4例当日资金为负；同花顺不能替代东方财富数值或混算。
5. **缺历史流通股本、市值和完整历史换手。**当前股本快照不能倒填到3月、6月，暂不建议加“当时小市值/换手率”条件。
6. **历史板块信息不完整。**当前概念成分不能冒充过去的归属，申万行业日线为空，涨停拆解在这些日期的个股覆盖有限，不能证明当时都属于热门板块。
7. **若要求盘中当天入池，需要另行核验分钟/实时数据。**本轮使用最终收盘价和全天成交量，只能确认收盘后的信号，不能证明盘中已能按这些最终值选出。

## 现有“自定义选股”可用的公式

建立同一个“全部满足”分组，分别添加下列6条；百分比使用数值1、2、10、35，不输入百分号。已用当前公式引擎对11例真实数据逐项求值，11/11全部通过。

```text
(MAX(high,20,1) / MIN(low,20,1) - 1) * 100 <= 35
```

```text
ABS(AVG(close,5,1) / AVG(close,5,16) - 1) * 100 <= 10
```

```text
(close / MAX(close,20,1) - 1) * 100 >= 1
```

```text
volume / AVG(volume,5,1) >= 1.2
```

```text
change >= 2
```

```text
high > low and (close - low) / (high - low) >= 0.6
```

如只要“今天首次突破近20日收盘箱顶”，再加`CROSS(close,MAX(close,20,1))`，会漏掉前述3例。若只要首次完整越过最高价，改加`CROSS(close,MAX(high,20,1))`，会漏斯莱克、杰恩、澳弘。这里仍是固定滚动窗口，并未自动寻找用户目测的箱体起点或对固定箱顶计算多次触碰。

研究比当前公式在数据有效性上更严格：额外要求窗口各日成交额为正且有限、最早一根涨跌幅有限；公式有浮点边界容差。这11例不受影响，其他股票若有这类异常，页面名单数量可能与研究不同。图表中的蓝色区域为收盘箱体，35%宽度条件则使用包含上下影线的高低区间，勿直接比较两种宽度。
