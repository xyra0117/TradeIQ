# 条件选股新：全历史 T+1～T+5 共性分析

生成时间：2026-09-14 18:20:20。仅使用本地 market_data.db；数据库以 mode=ro、query_only、只读事务读取。

## 核心结论

1. T+1～T+3：温和缩量（当日量为前一日的70%～80%）有一定优势；成交活跃和较大的历史振幅更容易带来次日冲高。按同日、同市场比较后，缩量比例的连续相关性明显减弱，不能单独当强信号。
2. T+3～T+5：入选日小单净流出，是这批数据里相对更稳定的区分项；近期主力资金相对成交额的强度有弱正向关系。
3. T+5：离MA60较近或仍在MA60下方的入选股票，相比已经明显远离MA60的股票，后续指标更好。全部样本本来就满足收盘不低于MA10，因而这里只描述短期回升、长期位置未过高的情形。
4. 9月11日单日观察到的“此前20日涨幅较大”和“半导体集中”，没有形成全时段稳定优势。此前20日涨幅超过15%的组，在T+2～T+5中位数反而较低；半导体没有持续领先。
5. 这是同一套筛选条件内部的事后关联研究；没有证明因果关系，也没有证明这套选股比全市场更好。最高点指标不等于能成交的收益。

## 范围与计算口径

- 资金源：eastmoney-push2。默认资金门槛3亿元，成交量比例上限80%。
- 原始规则：入选日下跌；价格低于200元使用主力，否则使用超大单；3/5/10/20窗口累计均为正，至少一项≥3亿元；当天收盘≥最近10个有效收盘价的均值；当天量≤前一有效记录的80%。
- 资金数据覆盖2026-06-16～2026-09-14，共64个记录日期。日线虽然更长，但更早缺少完整选股所需资金数据，无法扩展回溯。
- 707次“日期×股票”入选事件，457只股票，61个有入选的日期；入选事件范围2026-06-18～2026-09-14。当天刚入选、尚无后续行情的事件只计入名单，不计入各期表现。
- 一个股票多天入选会产生多个事件。另做同股票观察窗口不重叠的敏感性检查。
- T+1 = 第1天最高价÷入选日收盘价−1。
- T+N = 前N−1个交易日各自收盘涨跌幅的算术和＋第N日最高价相对前一日收盘价的涨幅。
- T+N不取前N天最高值，也不使用复利。各期指标可能下降。所有百分比均按用户确认的相加口径。
- 交易日按本地trading_dates_cache推进，不跨过缺失行情冒充T+N。实际收盘价变化与日线所记涨跌幅相差超过0.15个百分点时，排除该事件受影响的期数，以免除权参考价不一致等问题制造虚假涨幅。
- 每期独立选取该期指标最高的25%作为“高涨幅组”，其余75%作为对照。所有特征仅用入选日及以前数值；板块概念映射非历史快照，仅作描述。

## 数据质量与解释限制

资金流2026-07-31仅1000只、2026-09-01仅500只，明显小于常见的约5300只。应用规则允许“20日”窗口少于20条记录继续累计，这次为还原规则也保留，并另对满20条的268次事件复核。缺数据的日期不能理解为全市场没有其他符合条件的股票。

从当前原始表重建名单，和62个已有快照调用原筛选函数对比：运行时60个完全一致，2个日期存在差异。7月30日原始重建新增嘉美包装、没有岩山科技；岩山科技当前原始20窗口主力合计为负，而旧快照为正。9月11日重建多出大有能源，分析期间快照已被后台更新并包含该股。本报告以只读事务取得的原始表为准，不声称完整还原每个历史时刻用户实际看到的名单，也未修改或修复数据。

这也意味着上一轮9月11日的14只名单与本次按当前原始数据重建的15只有差异；原因是数据/快照状态变化，不是变更门槛。

本次8个事件在某一期出现价格参考口径不一致，对受影响期数及后续期数不计成绩；最新日期尚未走完相应周期也不计入对应分母。原始名单仍保留这些事件，明细的“—”表示该期不可用。

整体各期的收盘累计涨跌幅中位数均为负，而最高点指标中位数为正。这说明“盘中曾经冲高”和“持有到收盘赚钱”差别很大。本报告没有模拟买点、可成交最高价、交易成本和持仓组合，也没有用复利来计算收益。
