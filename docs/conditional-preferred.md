# 条件优选 v1

位置：选股 → 东方财富 → 条件优选（条件选股新旁）。

继承条件选股新的下跌、累计资金、MA10与缩量规则，以及页面当前资金门槛和成交量比例。默认3亿元、80%。

核心筛选：

- 入选日东方财富小单净额严格小于0。
- 最近5个本地交易日资金与成交额完整，主力净额累计 / 对应成交额累计不低于5%。成交额从千元换算到元；缺失记录不补0，不跳过缺日。

辅助排序：成交量为前日70%～80%、收盘不高于MA60，各记一项。优先按辅助命中项数降序，其次主力强度降序、代码升序。MA60不足60个有效收盘价不加分，不剔除。

这两个辅助项与核心规则的组合属于首版可解释策略，不代表已证明收益优势。历史研究只观察到单项关联。五交易日完整性要求比研究中的“最近5条可用记录”更严格，因此最终命中数可能少于研究时133次。

T+1只计算下一交易日最高涨幅。T+N将前N−1天各自收盘涨跌幅相加，再加第N天最高涨幅。页面下行展示同样相加口径的收盘累计，不取区间历史最大值、不使用复利。历史日线缺失或参考价偏差超过0.15个百分点时，该期及后续为空。

盘中例外：当今天正好是某个历史入选日的 T+1～T+5 时，该列使用新浪实时价和截至当前日高，标记“⚡实时/⚡最高”；前面已收盘交易日仍使用本地 `stock_daily`。当日涨跌幅以今日昨收计算，条件优选的累计值继续采用“前 N−1 日收盘涨跌幅算术和 + 今日实时涨跌幅或最高涨幅”。收盘日线入库后自动恢复权威日线口径。

接口：`GET /api/conditional-picks/preferred?date=YYYYMMDD&threshold_yi=3&volume_ratio_pct=80`。新计算只读，不新增表。基础名单复用现有条件选股新接口，因此继承它原有快照/原始数据回退行为。

页面顶部补充入选日市场背景：从本地 `overview` 精确读取同日上涨、下跌、平盘家数；没有该日记录时显示缺失，不回退到最近日期。上证指数、深证成指、创业板指、科创50统一按昨收换算成百分比分时曲线，便于横向比较。分钟数据必须经 `/api/index/minline` 核验为入选日；由于当前数据源不提供任意历史分钟回溯，缺失时保留明确提示，不展示其他日期曲线。

验证：`python3 -m unittest discover -s backend -p 'test_conditional_preferred.py'`；`node dashboard/test-conditional-preferred.cjs`。同时回归条件选股新和指数图表，浏览器验证Tab、日期/门槛切换、空状态、股票K线及资金弹窗。
