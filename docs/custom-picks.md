# 自定义选股

独立放在“选股推荐 → 东方财富 → 追高选股”右边。低吸和追高保持原有设置。

## 交互

用户可通过点选指标、输入公式或中文生成草稿添加条件；新条件可改名、编辑、关闭和删除，删除后可以撤销。每组选择全部满足或任一满足，组间同样可以选择全部或任一满足。空组和关闭条件不参与判断；没有开启条件时不生成名单。

条件变更自动保存到当前浏览器，并重新筛选，同时同步到后端（见下节“条件同步”）。中文生成的条件需先核对解释、公式及目标组的且/或关系，再点击加入；无法完整识别时显示原句并阻止加入。中文入口支持列明的本地语法，并不假装理解任意投资概念。公式提供更广泛的自定义组合。“10日涨幅”按收盘累计涨幅解释；含义不明的周期描述拒绝解析，不静默改成平均值。

标题标签独立计算当天全市场符合数量，关闭条件也统计。零符合且有可核验数据时显示“全军覆没”；无可核验数据时显示“数据不足”。诊断显示逐项移除后的入选数量，试算不改设置。结果按代码分页，支持搜索、T+1至T+5和既有个股弹窗。

“🖼 生成预览图”把当前日期的结果画成一张PNG长图，版式与“条件选股新”一致：深色底、四列卡片（序号 / 名称 / 代码），标题写“自定义选股 · 年月日 · 命中 N 只”，下面一行副标题写开启的条件名。后端按当前条件全市场筛一次取全量命中（不受分页限制），命中超过200只时图上只画前200只并在副标题注明总数。文件名带条件指纹，同一套条件重复生成覆盖同一个文件，换条件另存一张，存到 backend/previews/。

## 条件同步

条件原本只存在各浏览器的 localStorage 里，多台电脑各存一份，同步不了。现在条件以**后端为唯一真相源**：后端把条件存在 backend/custom_picks_config.json，连同一台后端的所有设备（多台电脑、手机）共用一份；浏览器本地仍留一份缓存，服务器连不上时照常离线可用。

同步规则：

- 打开“自定义选股”页面、切回窗口、每30秒各拉一次；服务器上的版本号（rev）比本机新，就用服务器那份并提示“已从另一台设备同步最新条件”。
- 本机改动后立即上传（防抖0.7秒），谁最后改谁说了算。
- 服务器上还没有条件时，本机有条件就认领上传（空条件不认领，免得把另一台电脑设好的条件顶掉）。
- 本机有从没同步过的条件（另一台电脑刚设好的那种）且不比服务器上的旧时，以本机为准推上去，不被先同步的版本顶掉。
- 正在编辑条件或还有未上传的改动时，不拉远程打断；同步失败只在状态行提示，不影响本机使用。

两台电脑各改各的条件无法合并，后保存的会覆盖先保存的。条件文件是用户数据，已加入 .gitignore，不入库。

## 公式口径

字段：open / high / low / close（元），change（百分数，例如5表示5%），volume（沿用本地日线单位，仅用于同口径比较），amount（亿元），main_net / super_net / big_net / mid_net / small_net（东方财富净额，亿元），amplitude（日振幅百分数），limit_up（收盘涨停真假），up_count / down_count / flat_count（家），sh_change（上证涨跌幅百分数）。

函数：SUM / AVG / MAX / MIN(expression, n, offset=0)，REF(expression, n)，MA(n)，RET(n)，COUNT(predicate, n, offset=0)，ALL / ANY(predicate, n, offset=0)，CROSS(left, right)，ABS(expression)。窗口含当前引用日；offset=1排除引用日。REF仅引用过去，RET(n)为收盘相对n个交易日前的累计涨幅。CROSS为当前严格大于、前一日小于或等于。连续递减可写 ALL(volume < REF(volume, 1), 3)。

支持算术、比较及and / or / not。金额统一用亿元；SUM(main_net, 5) / SUM(amount, 5) * 100 > 8 表示5日主力强度超过8%。成交额原始千元转换为亿元，资金原始元转换为亿元。涨停使用原策略历史板块规则；新上市且缺少价格参考时记为数据不足。

窗口1至250个交易日，累计最远引用不得超过250个交易日前。每条件必须产生真假结果；非法字段、调用、未来引用、过长或过深的公式被拒绝。除零、缺日、非有限数、无效日线、参考价异常均为数据不足。AND中一个明确不符合足以判不符合，OR中一个明确符合足以入选，其余未知保留为未知。

## 数据与接口

只读现有stock_daily、fund_flow、overview、index_daily及交易日历。资金仅使用东方财富已核验同口径来源，不使用同花顺。各指标仅要求自身所需窗口完整，不让未使用字段的缺失阻止短期指标。选股与数量统计不读取未来结果；名单确定后才附加T+1至T+5，使用既有复利口径。

GET /api/picks/custom/catalog 提供字段与函数说明；POST /api/picks/custom/validate 校验单条公式；POST /api/picks/custom/parse 生成中文规则草稿；POST /api/picks/custom/screen 查询名单、独立数量、条件诊断及所选股票核验；POST /api/picks/custom/preview-image 按当前条件生成PNG预览图，返回 {status, date, count, shown, url, path}；GET /api/picks/custom/config 读后端保存的条件（没有时 config 为 null），POST /api/picks/custom/config 保存条件（每次保存 rev+1）。行情数据仍只读，条件配置写在 backend/custom_picks_config.json，不写行情数据库。
