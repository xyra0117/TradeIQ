## 参考图转化为新框架

浅色参考保留：窄侧栏、弱分隔线、清楚的表头、低干扰工具条和黑色选中态。深色参考保留：接近黑色的底、深灰表面、灰阶导航与明亮主文字。

TradeIQ 的主要任务是比较股票和回看图表，因此收紧导航宽度、卡片高度与纵向空白，把可用空间优先给结果表。应用外壳铺满浏览器，取消旧页面的 1400px 内容限宽。参考图里的大额账户卡片和宽侧栏不直接沿用。

## 布局与信息层级

| 区域 | 设计规格 | 作用 |
| --- | --- | --- |
| 左侧导航 | 展开 208px，收起 64px；保留八个主要入口 | 一级功能位置稳定，可让出表格空间 |
| 顶部工具条 | 64px；交易日、前后日期、刷新和双主题 | 页面操作集中，不挤入策略标签 |
| 主区 | 两侧各 24px；宽度随窗口增长 | 充分使用宽屏，而不把内容集中在中间 |
| 数据源与策略 | 数据源分段控件、策略下划线标签 | 让一级页面、数据源和策略的层级清楚 |
| 同日市场 | 一条紧凑摘要；四指数图按需展开 | 保留市场上下文，默认不占据大块高度 |
| 结果表 | 数字约 13px，双行结果行高 52px | 显示股票、条件指标及 T+1～T+5 |
| 表格滚动 | 表头与名称列固定；滚动只发生在表格内 | 宽列仍能比较，整体页面不横向溢出 |
| 个股详情 | 560px；1760px 及以上并排，较窄窗口覆盖 | 查看时保留列表上下文，关闭后收回空间 |

默认规则收起；辅助条件是明确的命中项数，不重新设计预测评分。最高累计与收盘累计用上下两行区分；各策略正式计算必须延续自己的既有口径。

## 黑白视觉体系

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面底色 | `#F5F5F3` | `#101112` |
| 内容表面 | `#FFFFFF` | `#171819` |
| 侧栏 | `#F0F0EE` | `#131415` |
| 主文字 | `#1D1E20` | `#EDECE8` |
| 分隔线 | `#E5E6E1` | `#2B2D2F` |
| 上涨 / 资金流入 | `#BC514F` | `#D67571` |
| 下跌 / 资金流出 | `#39876F` | `#74B79B` |

主要按钮及选中态使用黑白反差，边框与表面用灰阶区分。红绿只表达行情、资金和相应图形；不作为导航装饰。圆角集中在 4—8px，采用细边框，主界面没有渐变或发光背景。

中文使用本机苹方并保留思源黑体回退，品牌使用 Avenir Next 回退；数字使用 Menlo / JetBrains Mono 等宽字族，固定数字对齐。原型不从外部加载字体。

全部界面图标采用用户指定的 [Remix Icon](https://remixicon.com/) line 系列，固定版本 **4.9.1**。仅保存实际需要的 28 个 SVG 图标，本地合并为 `icons.svg`；版本、图标名和源文件摘要记录在 `remixicon-manifest.json`，完整许可保存在 `REMIXICON-LICENSE.txt`。
