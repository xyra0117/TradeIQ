# TradeIQ 桌面工作台设计规范 v1.11

初版：2026-10-04；v1.11更新：2026-10-10。适用范围：`dashboard/redesign/` 桌面新版及其后续页面。

这是一套从已完成的黑白工作台中提炼的设计基线，覆盖视觉、布局、组件、交互和数据表达。它以当前页面实现为依据；新增的统一规则与尚未完成的工程工作在末尾单独标明。现有前端入口保持独立。

规范同时以[UI视觉组件展示页](../../dashboard/redesign/components.html)呈现，可通过本地 `/dashboard/redesign/components.html` 访问。支持浅色、深色、并排对照及目录/搜索；新版工作台侧栏提供“UI视觉组件”入口。

展示覆盖14类：语义色彩、文字数字、间距形状、Remix图标、导航切换、按钮操作、输入选择、标签数据卡、数据表格、价格资金图、反馈状态、日期浮层、工作台组合、业务功能组件。交互仅使用虚构样例，不调用业务接口。展示页读取工作台现有主题变量并复用控件样式，不另建主题体系。v1.1业务功能组件对应本轮23组缺失UI补齐，原v1.0组件验证与素材保留为历史记录。

## 1. 设计原则

1. **优先阅读与比较数据。** 主区随窗口展开，先保证表格、图表和名称列的空间，再安排说明与操作。
2. **用灰阶建立层次。** 页面、侧栏、内容面、选中态与边框形成层级；不增加装饰渐变或发光。
3. **颜色帮助辨认含义。** 黑白灰表达导航与操作，低饱和红绿表达行情与资金方向；业务状态、板块归属与热度使用各自的语义色点缀。
4. **紧凑但保持可读。** 常规文字与数值有稳定尺度；复杂信息按需展开，不把所有规则常驻在页面上方。
5. **操作后保留上下文。** 查看详情、调整列或重试时，保留当前日期、筛选、排序和滚动位置。
6. **业务口径清楚。** 日期、来源、单位、缺失、观察池用途与收益口径都是界面信息的一部分。

## 2. 布局基线

| 区域 | 当前规格 | 使用规则 |
| --- | --- | --- |
| 应用外壳 | 浏览器全宽、全高 | 主区不设居中最大宽度；禁止页面整体横向溢出 |
| 左侧导航 | 展开208px，收起64px | 八个一级入口位置稳定；收起后保留图标、名称提示及选中态 |
| 顶部工具条 | 高64px | 日期、前后交易日、刷新、个股搜索、数据状态与主题集中放置 |
| 主区边距 | 左右24px；当前顶部23px | 正常桌面宽度沿用；新页面顶部统一以24px为目标 |
| 功能层级 | 一级页面 → 数据源 → 策略/子页面 → 筛选 → 内容 | 同一层级使用同一种切换方式 |
| 个股详情 | 宽560px | 窗口≥1760px时与列表并排，≤1759px时采用覆盖抽屉 |
| 普通弹窗 | 最大宽780px，左右至少24px | 用于录入、计算器、设置与简短确认 |
| 宽弹窗 | 最大宽1160px，左右至少32px | 用于图表、字段映射、导入预览与历史统计 |
| 弹窗高度 | 不超过视口高度减64px | 内容可滚动，标题与关闭入口保持可见 |

窗口宽度检查以1440、1920、2560px为准。窄窗口允许工具条换行、图表与卡片减少列数；宽表仍在表格内部滚动。当前板块卡片在1440px为3列、1920px为4列、2560px为5列。手机独立只读版不套用本规范的桌面验收标准。

四种页面构成沿用同一外壳：指数页使用摘要与图表；筛选页使用规则、筛选与宽表；持仓页使用账户汇总与操作表；板块页使用卡片与详情。内容结构按用途变化，视觉规则保持一致。

## 4. 字体与数字

| 类型 | 当前字体/字号基线 | 用途 |
| --- | --- | --- |
| 中文正文 | 苹方；回退思源黑体、微软雅黑；14px，行高1.5 | 正文与主要说明 |
| 品牌 | Avenir Next，回退中文字体；20px | TradeIQ品牌文字 |
| 数字 | Menlo，回退JetBrains Mono、monospace | 金额、价格、涨幅、日期与代码 |
| 页面标题 | 25px，字重550 | 一级页面名称 |
| 股票详情标题 | 24px，字重550 | 个股名称 |
| 弹窗标题 | 19px，字重550 | 弹窗任务名称 |
| 主要指标 | 常用25px，窄屏22px；详情价格32px | 总成交额、市值、价格等主要数值 |
| 区块标题 | 13–15px，字重550–600 | 表格、卡片与图表标题 |
| 表格正文 | 13px；表头12px | 主要结果与比较数据 |
| 操作文字 | 11–13px，按组件密度选择 | 按钮、筛选、标签与次级切换 |
| 辅助文字 | 当前9–11px | 代码、图注、次要刻度与补充说明 |

必要的规则解释、错误说明与主要数据不能只放进9–10px辅助文字。下一阶段统一组件时，正文、表格和辅助文本应分别定义固定字号档位，减少散落的局部字号。

股票名称与普通描述左对齐；数值、金额及百分比右对齐。同一列精度和单位一致；涨幅保留正负号，图表与表头明确标出单位。不能因为缩放字体而让数字与单位重叠。

## 5. 间距、圆角与线条

新增组件以4px为基础间距步长，优先使用4、8、12、16、20、24、32px。当前页面仍存在7、9、15、17、18、23px等局部值，这些是现状记录，并非已完成的统一间距系统。

| 位置 | 统一方向/当前基线 |
| --- | --- |
| 控件内部及图文间距 | 优先4或8px；小控件允许按图标视觉中心微调 |
| 卡片之间 | 当前常用14–18px；新增模块优先16px |
| 模块之间 | 当前常用18–20px；新增模块优先20或24px |
| 主区边距 | 24px |
| 内容卡片 | 圆角8px、1px细边框 |
| 按钮 | 圆角6px；紧凑图标按钮4px |
| 输入、选择控件 | 当前圆角5px |
| 标签、图表范围条 | 圆角4px |
| 弹窗外壳 | 圆角10px |
| 曲线 | 主次线用灰阶、粗细与虚实区分；网格比内容更弱 |

圆角按组件类型使用，不能随单个页面喜好改成大圆角。1px边框、2px选中下划线不属于布局间距步长。

## 6. 组件使用规范

| 组件 | 规格与使用场景 | 状态与行为 |
| --- | --- | --- |
| 主要按钮 | 高34px，黑白反差；用于当前任务的关键动作 | 具备默认、悬停、焦点、禁用及处理中状态；同一局部任务区只突出一个关键动作 |
| 次要按钮 | 高34px，内容面底色、细边框 | 用于导入、刷新、返回、次级任务 |
| 紧凑按钮 | 当前常用30–32px | 用于表格工具区；不承载长说明 |
| 图标按钮 | 30×30px，图标18px或15px | 必须提供名称提示及可访问名称；禁用时不能触发 |
| 搜索与筛选 | 搜索/常规选择控件高32px；表单输入高36px | 标签明确，保留值；键盘焦点可见；长控件换行而不覆盖相邻操作 |
| 数据源切换 | 黑白分段控件 | 东方财富、同花顺、我的选股属于同一切换层级 |
| 时间范围切换 | 复用`period-pills`分段控件：容器3px内边距、6px圆角、1px边框；按钮11px、4px圆角 | 选中面使用`--selected`、文字使用`--ink`；时间轴区间同样使用`--selected`实底和`--line-strong`边界，手柄使用`--secondary` |
| 策略/子页面切换 | 高39px，下划线选中态 | 选中项使用主文字与2px下划线；空间不足时在标签区滚动 |
| 卡片/指标摘要 | 内容面、8px圆角、细边框 | 数值高于标签和备注；不把所有指标都设为大字号 |
| 标签 | 弱背景、4px圆角、小字 | 用文字表达状态、来源、辅助命中；不能暗示未经证实的预测结论 |
| 抽屉 | 560px，右侧打开 | 显示摘要、价格图、资金图；可关闭、切股票、放大与还原 |
| 弹窗 | 780/1160px两档 | 标题、关闭、内容与任务动作清楚；长内容内部滚动 |
| 短提示 | 小浮层 | 只用于短暂操作反馈，不能替代持续错误提示 |

现有实现对不同层级保留少量尺寸差异。后续组件化应沿用以上档位，不新增多套高度和视觉状态。

### 功能补齐组件基线（2026-10-04）

- 日期模式与历史范围分开表达：全部日期、最近收盘日、今日实时、指定日期依页面语义提供；条件优选另有市场背景查看日期，不能改变入选日期。简易版提供市场总览、晴雨表、个股搜索、选股推荐四个入口，进入时默认市场总览。
- 自定义资金门槛和缩量比例使用现有32px输入档位及清晰单位；不同策略独立保存演示参数。低吸/冲高不展示条件选股的统一门槛。输入不合法时显示字段错误，不执行示例筛选。
- 来源名单使用行内“加入我的选股/已加入”组件；去重按示例股票与入选日判断。添加按钮与名称区并排，保持双行记录的紧凑高度；名称列可适当加宽，不为按钮再增加一行。确认表的复选框采用当前主题灰阶。历史统计同时提供摘要、分桶数量/比例与样本表，筛选独立于入选名单。
- 方案卡复用8px卡片，显示可行、不可行、已采用、失效、到价状态；提供调整和取消。减仓结果同时列出费用、剩余仓位及前后盈亏示算，结果标注虚构账户。
- 自选板块使用核心/同领域两组各三位置，表单显示角色和排名；替换、移除及整板块移除先展示明确的演示确认弹窗，不执行实际删除。
- 导入按持仓/成交/OCR分别提供字段和预览，包含有效、重复、缺必需列、待重新应用、失败/部分成功状态。进度和失败信息持续显示，不能只用短提示。
- PNG预览包含生成中、失败重试、下载、复制链接组件；示例下载仅导出内置虚构内容，链接指向本地预览，无实际上传或公开发布。
- 图表组件补齐MA5/10/20/30/60、成交量/成交额、MACD、资金净额/净占比、交易标记及多选图例；鼠标指针、范围滑条、滚轮缩放与拖动在示例图内联动。所有图形及数值明确标注示例，不代表已验证真实行情。
- 简易版市场总览增加两组独立多轴趋势组件：上证/科创50与超大单/小单共用日期轴，指数右轴(点)、资金左轴(亿元)；涨跌家数、成交额、主力净流入使用家数右外轴、成交额右轴(亿元)、资金左轴(亿元)。资金显示虚线零轴。每图独立提供近10/20/60日、全部、图例多选、指针提示、缩放与拖动，以及起止区间控件；所选日期为图表截止日期，日期变更后重置至近10日。浅深主题共用语义色，指数与成交额用灰阶实线/虚线区分，涨跌家数保留低饱和红绿。不同单位按轴和提示分别注明，不统一成相同量纲。该组件同时在业务功能组件中展示。
- 市场总览采用紧凑指数卡（14px内边距、25px微趋势），主趋势绘图区210～280px高；优先让1920×1080窗口同时看到两图与完整区间控件。较矮窗口在内容区滚动，不压缩必要的单位和图例。

## 7. 表格规范

- 普通功能表的表头约43px、行高44px；条件优选的双行表头约53px、双行结果行高52px。
- 股票名称列与表头固定。表格内可横向、纵向滚动，外层页面不随宽列横向溢出。
- 股票名称、代码与板块分层；名称是详情入口。必要的宽字段通过列设置调整，不压缩成无法阅读的文字。
- 排序方向可见，当前排序保持稳定。筛选、搜索、列设置与详情切换不能意外重置结果上下文。
- T列需要给出对应日期及当前策略的口径。最高结果与收盘结果可用上下两行区分；不能只放一个没有定义的“收益”。
- 缺失显示“—”并解释原因，不能用0冒充；数据异常不能直接给出通过状态。
- 行悬停与选中使用弱灰阶反馈，金额与行情颜色不随选中态改变含义。
- 逐行操作采用文字或带明确名称的图标；涉及移除记录时，区分演示移除与实际数据操作。

## 8. 图表规范

图表铺满所属容器的可用宽度，坐标与提示文字保持正常尺度。价格图、资金图、市场分布图均覆盖浅色与深色，主题切换不只改变外壳。

主次曲线优先用灰阶、实线/虚线与图例区分；涨跌K线与正负资金柱使用对应方向色。图例、坐标、单位与时间区间明确，不能只靠曲线颜色判断指标。

指数分时显示所选交易日；缺少该日数据时说明缺失。股票价格、资金净额、净占比采用同一区间，正式图表的指针与范围应同步。切换股票或指数后，旧响应不能覆盖新选择；指数弹窗和交割分析的图表设置与个股详情相互独立。

目前原型使用虚构图形和示例区间。上述正式数据核验与真实图表联动，是接入阶段的要求，不能解释为已经由原型完成。

## 9. 图标规范

统一使用用户指定的[Remix Icon](https://remixicon.com/)。当前固定版本4.9.1，本地40个SVG。

- 常规功能使用line系列，已收藏状态使用对应star-fill。
- 常规图标18px，紧凑图标15px；10–12px的小图标仅用于次级状态标记。
- 图标跟随文字颜色，用 `currentColor`，不单独增加装饰色。
- 图标在同一操作中含义稳定：日期、搜索、刷新、列设置、关闭与放大不随页面换图形。
- 常用文本动作优先“图标+文字”；仅图标动作提供名称提示。
- 新增图标继续合并到本地SVG，并同步来源清单与许可，不引入另一套图标库。

## 10. 交互、状态与文案

日期表达遵循当前页面语义：筛选日、行情日、成交日与实时/收盘状态不能混用。来源切换保留各自策略层级，不能用一份数据冒充另一来源。

规则默认收起，市场背景按需展开。关闭详情恢复列表空间，保留筛选、排序和滚动；不同视图分别保留本次会话的滚动位置。Esc逐层处理当前弹出菜单、弹窗、放大详情与详情关闭，避免同时关闭背后的任务。

| 状态 | 必须说明 | 可执行动作 |
| --- | --- | --- |
| 加载中 | 正在读取哪一类数据 | 保留日期和筛选；重复提交受到控制 |
| 空结果 | 无记录或不满足条件，而非读取失败 | 清除筛选、调整条件或日期 |
| 部分缺失 | 缺少哪个指标/日期及其影响 | 留空相应字段，仍可阅读有效部分 |
| 请求失败 | 暂时无法读取；保留当前任务上下文 | 重试当前请求，不强制重置筛选 |
| 完成 | 哪项任务完成、有效数量或结果 | 返回工作台或继续查看 |
| 表单错误 | 错误对应具体字段，修正方法明确 | 错误纠正后允许提交 |

文案默认中文，动作使用具体动词。单位放在表头、标签或图例中；日期与来源在同屏可见。数据完成、覆盖不足、历史研究、观察池和示例演示不能用模糊“正常”替代。

同花顺总资金与东方财富主力、中小单独立表达。低吸与冲高不新增预测评分；冲高观察明确“不是买入信号”。辅助命中表示规则命中，不能包装为收益预测。

## 11. 键盘、动效与偏好

默认颜色/背景过渡约150ms；焦点显示2px描边，偏移3px。加载图标可旋转；系统要求减少动效时关闭非必要过渡和动画。不给装饰效果增加行情阅读负担。

关键控件提供键盘焦点、名称和选中/展开状态。不得只靠红绿、悬停或动画提供必要信息。

主题及侧栏偏好使用新版独立键前缀 `tradeiq_redesign_`。当前条件优选的列偏好持久保存；其他页面列设置保存在会话内存中，不能把所有页面列偏好都描述为已实现持久保存。
