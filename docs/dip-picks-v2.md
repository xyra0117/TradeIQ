# 低吸选股2.0

入口：选股推荐 → 东方财富 → 低吸选股2.0。接口：`GET /api/picks/dip-v2?date=YYYYMMDD`。

这版在[原低吸选股](dip-picks.md)的全部条件上，再筛出价格更接近均线、近5日资金买入力度更强的股票。原低吸选股仍独立保留。资金源为东方财富，不混合同花顺。

## 新增三个必选条件

| 条件 | 明确口径 | 大白话 |
| --- | --- | --- |
| 收盘相对MA20偏离≤5% | `(收盘价/MA20−1)×100 ≤5`；原条件已要求收盘>MA20 | 价格在20日线上，但最多只高5% |
| 收盘≤MA60 | MA60为入选日及此前59个交易日收盘均值 | 价格已经回落到60日线或下面 |
| 5日主力强度≥5% | `近5日东财主力累计净额/(同5日成交额合计×1000)×100 ≥5` | 最近5天，每成交100元，主力净流入至少5元 |

三个新增条件必须同时满足；等于5%、等于MA60都允许。日线成交额单位为千元，资金净额单位元。5日资金、成交额窗口均包含入选日；成交额逐日缺失、非有限、≤0时不能评估，不跳过、不补零。20日线/60日线只读筛选日及此前收盘。仍不要求当日主力净额为正。

## 研究依据与使用边界

依据[2026-10-02本地研究报告](dip-picks-research-20261002.md)：价格更靠近均线的样本，五天每天有正向冲高机会的比例相对较高；近5日主力净额占成交额更高的样本，曾冲高超过10%的比例相对较高。MA60下方的关联在前后时段、去重检查中方向延续。

三项采用报告里已经比较过的固定阈值，并要求同时满足；没有根据未来涨幅调节阈值。报告只验证各项样本内关联，没有证实这个组合可稳定预测收益。因此页面标为“历史研究 · 试验策略”，不展示买入评分或历史胜率宣传。

以报告201次完整样本复核，三项交集为13次、12只股票、6个入选日；这只是覆盖统计，不能视为独立验证。名单少或为空是更严格筛选的正常结果。

## 展示和实现

- 原低吸指标及T+1～T+5最高/收盘累计涨幅均保留；增加MA60、距20日线百分比、5日主力强度。
- 展示原低吸入选数量，以及“离20日线过远”“高于60日线”“成交额缺失或异常”“5日主力强度不足”的筛除数量；按此顺序计数，每只股票仅归入一个首个未通过项。
- 两版共用页面布局、日期控件、K线及资金弹窗，保留独立名单和响应缓存；切换日期/Tab时旧响应不得覆盖新视图。
- 原筛选成交量比仍是当日量/此前5日均量，均值不含当日；新资金强度是另一个指标。
- 未来T+N仅用于入选后展示，原收盘名单不由实时价格或未来数据改变。缺日/价格参考不符时沿用原缺失说明。
- 在 `backend/dip_picks.py` 扩展，只读SQLite `mode=ro`、`query_only=ON`，没有新增表、数据迁移或后台任务。
