# 追高选股

入口：选股推荐 → 东方财富 → 追高选股。原名“低吸选股2.0”，沿用接口：`GET /api/picks/dip-v2?date=YYYYMMDD`。

这版沿用[原低吸选股](dip-picks.md)的资金、120日涨幅、成交量、MA20和振幅条件；将“当日下跌”替换为“当日涨幅超过5%”，增加收盘未涨停及均线多头排列。大盘条件独立，原低吸选股仍独立保留。资金源为东方财富，不混合同花顺。

大盘条件：`同日下跌家数 <2600 AND 上证当日涨跌幅 >0`。下跌家数恰好2600家、上证平盘或下跌都不触发；不检查此前三个交易日走势或1.6%跌幅。下跌家数取同日 `overview.downCount`，上证涨跌幅取同日 `index_daily` 的“上证指数” `change`，兼容两种日期格式；必要数据缺失或异常时不推荐，不用其他日期代替。

## 当前个股条件

所有下述策略条件默认开启，现可逐项关闭以比较名单；正文中的必选、缺失排除说明仅适用于相应条件开启时。原低吸选股不受影响。

## 条件开关

`GET /api/picks/dip-v2?date=YYYYMMDD&disabled=volume,amplitude,bullish` 关闭指定条件，其余保持开启；不传参数保持原完整策略。未知条件键返回400，不静默忽略。关闭全部11项时，返回筛选日有效收盘日线股票，关闭后的字段能计算则展示，无法计算显示空值；不以缺失字段补零。

| 条件键 | 开关条件 |
| --- | --- |
| market_down | 下跌家数 <2600 |
| market_up | 上证当日上涨 |
| gain | 个股当日涨幅 >5% |
| return120 | 120日涨幅 <300% |
| funds_red | 3/5/10/20日主力累计净额全部 >0 |
| funds_threshold | 任一3/5/10/20日主力累计净额 >0.5亿元 |
| volume | 当日量 / 前5日均量 <1.2 |
| above_ma20 | 收盘价 >MA20 |
| amplitude | 20日平均振幅 ≥5% |
| not_limit | 收盘未涨停 |
| bullish | 收盘 >MA5 >MA10 >MA20 >MA60 |

资金两个开关互相独立，均不使用当日主力净额作为门槛。均线多头包含收盘>MA20，所以单独关闭MA20条件而保持多头开启可能不增加股票。

仅要求已启用条件的必要数据：120日涨幅需要121日日线，多头60日，振幅21日，量比6日，MA20需20日，未涨停及涨幅参考核验需2日；资金任一开关开启需要连续20日同源资金。数据质量及对应窗口价格参考核验不作为可关闭策略条件；缺日/异常时不计算该窗口。关闭大盘条件时该项数据缺失不阻止筛选，仍显示同日可用大盘信息。

响应 `conditions` 回显各项启用状态，`required_history_days` 标明必需日线窗口。界面开关立即重筛，使用本地存储键 `tradeiq.chase.disabled.v1` 保存关闭条件，刷新、跨日期和Tab后保留；可一键恢复全部开启并保存。非法、旧或损坏的偏好只恢复有效的当前条件键，存储不可用时仍允许当前页面操作。显示当前启用条件、关闭条件和同日上次/本次数量变化。快速切换开关时旧响应不能覆盖新组合。T+1～T+5只在名单确定后补充，不影响名单。

### 全市场单项符合数量

只读 `GET /api/picks/dip-v2/condition-counts?date=YYYYMMDD` 返回同日 `stock_daily` 收盘价>0的全市场日线股票总数，以及11项条件独立的 `matched` / `evaluated` / `missing` / `total`。不受任何开关、其他条件或最终名单影响；指标公式及价格质量核验与实际筛选共用。个股条件仅要求自身的连续窗口完整，资金条件仍要求连续20日东方财富资金。统计不读筛选日之后的数据。

标题标签：有匹配显示“N个符合”；可评估但零匹配显示“全军覆没”，悬浮说明已核验数量和缺失数量；没有可评估数据、未收盘或无同日日线显示“数据不足”，不把缺失假装成零匹配。大盘条件对所有股票统一生效，满足时所有同日日线股票符合，不满足时全军覆没；大盘数据缺失显示数据不足。

统计与筛选名单分别加载，日期改变立即清空旧标签并重算；开关改变复用同日统计。点击刷新结果重新获取统计；加载或失败明确显示，不保留其他日期的数值。原低吸接口及名单保持独立。

## 未入选诊断

空名单自动显示“为什么没选出来”，有名单时可主动查看条件影响。`/api/picks/dip-v2/diagnostics`与低吸诊断同口径：按当前开关分别模拟单项关闭，当前及所有单项均0时再检查两项组合；大盘未通过、数据不足和条件组合分别说明。提供分页模拟名单及未通过的关闭条件，模拟不改变开关，点击“应用此组合”才保存并重筛。日期/策略/配置守卫防止旧诊断覆盖。详细参数与只读限制同低吸文档；不输出收益预测或自动放宽规则。

## 市场温度

追高与低吸复用条件优选的市场温度外观与绘制逻辑，显示上涨/下跌/平盘家数、比例条及四大指数分时。默认查看筛选日，可用左右箭头查看T+1～T+5；同日刷新保留查看日，切换策略或筛选日重置。温度日期不改变名单、开关及收益展示。名单为空或大盘未触发也能查看，后续日期读取本地交易日历；数据缺失、请求失败或日期不符时明确说明，绝不使用其他日期替代。沿用现有查询接口，温度控件和图表实例与条件优选隔离，异步守卫同低吸。

## 默认个股条件明细

| 条件 | 明确口径 | 大白话 |
| --- | --- | --- |
| 当日涨幅>5% | 同日 `stock_daily.change >5`；恰好5%不入选，替代原“当日下跌” | 当天已经上涨超过5% |
| 收盘未涨停 | 收盘价严格低于按板块及日期计算的涨停价 | 收盘还没有封住涨停；盘中触板后回落可以入选 |
| 均线多头排列 | `收盘价 > MA5 > MA10 > MA20 > MA60`；所有均线包含筛选日 | 股价在均线上，短期均线依次高于长期均线 |

三个条件必须同时满足；等于5%、任意相邻均线相等、收盘等于MA5或涨停价均不入选。仍保留：120日涨幅<300%、3/5/10/20日主力累计净额全部>0且任一项>0.5亿元、当日量/此前5日均量<1.2、收盘>MA20、近20日平均振幅≥5%。使用连续121日日线和连续20日东方财富资金；缺失或参考价异常不入选。当日主力净额仅展示，不要求为正。

## 涨停口径

涨停价为 `前一交易日收盘价 × (1+涨停比例)`，Decimal按四舍五入取到0.01元。按代码识别板块：主板通常10%，创业板及科创板20%，北交所30%。主板风险警示股票在2026-07-06之前按当日日线名称中的ST标识使用5%，之后使用10%；不以最新ST状态改写历史日。创业板2020-08-24前使用当时的10%（ST为5%）。无法判断的代码或必要名称缺失时，不填默认涨停价。

规则来源：[上交所2026年交易规则修订说明与实施日](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20260424_10816474.shtml)、[深交所2026年交易规则](https://investor.szse.cn/lawrules/rule/trade/t20260424_620190.html)、[创业板交易规定](https://investor.szse.cn/knowledge/t20200729_580056.html)、[北交所交易规则](https://www.bse.cn/jygl_list/200028217.html)。

原第7/8/9项（距MA20≤5%、收盘≤MA60、5日主力强度≥5%）已取消。当前筛选不读取成交额，不再计算5日主力强度。旧[研究报告](dip-picks-research-20261002.md)保留为历史材料，旧规则的覆盖统计不代表本版表现。页面标为“试验策略”，不展示收益预测或历史胜率宣传。

## 展示和实现

- 保留资金及T+1～T+5最高/收盘累计涨幅，展示MA5/MA10/MA20/MA60；撤下旧距20日线和5日主力强度字段。
- 展示“涨幅超5%”候选覆盖及“基础条件”匹配数量（涨幅>5%且满足保留条件的数量），再展示涨停价无法核验、收盘涨停、均线非多头的筛除数量；每只股票仅归入一个首个未通过项。
- 两版共用页面布局、日期控件、K线及资金弹窗，保留独立名单和响应缓存；切换日期/Tab时旧响应不得覆盖新视图。
- 成交量比仍是当日量/此前5日均量，均值不含当日。
- 未来T+N仅用于入选后展示，原收盘名单不由实时价格或未来数据改变。缺日/价格参考不符时沿用原缺失说明。
- 在 `backend/dip_picks.py` 扩展，只读SQLite `mode=ro`、`query_only=ON`，没有新增表、数据迁移或后台任务。
