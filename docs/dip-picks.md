# 低吸选股

入口：选股推荐 → 东方财富 → 低吸选股。接口：`GET /api/picks/dip?date=YYYYMMDD`。

日期为空时使用最近可用收盘日；指定日期使用该交易日的收盘数据，不以最新大盘、资金或实时价替代历史数据。盘中等待收盘，必要行情或资金缺失时不入选。结果只表达条件匹配，不计算预测评分。

## 大盘触发条件

`下跌家数 > 2800 AND ((-2 < 上证涨跌幅 < 0 AND 非此前三日连涨) OR 上证涨跌幅 < -2)`。

- 下跌家数取同日 `overview.downCount`；上证涨跌幅取同日 `index_daily` 中“上证指数”的 `change`（百分数）。兼容数据库日期的 YYYYMMDD / YYYY-MM-DD 格式。
- 前三日是筛选日之前三个交易日，不包含筛选日；三日涨跌幅均 >0 才算连续上涨，平盘不算上涨。
- 恰好跌 −2% 不满足两条严格不等式；下跌家数恰好 2800、上证平盘或上涨也不触发。
- 上证跌幅超过 2% 时不需要前三日状态。未满足条件显示“不推荐”及原因；缺必要大盘数据则显示“数据不足”。

## 个股筛选条件

全部满足以下条件才入选，不从其他策略的名单二次过滤：

| 条件 | 计算公式 |
| --- | --- |
| 当日下跌 | 当日 `stock_daily.change < 0` |
| 120日累计涨幅 <300% | `(筛选日收盘 / 120个交易日前收盘 − 1) × 100 <300`；不是股价上限，也不是日涨跌幅的算术和 |
| 资金全红 | 东方财富 `main_net_inflow` 的最近3/5/10/20个交易日累计值全部 >0；各窗口包含筛选日 |
| 任一累计资金项 >0.5亿元 | 上述四个累计值中的最大值 >50,000,000元 |
| 5日均量小于1.2倍 | `筛选日成交量 / 此前5个交易日成交量均值 <1.2`，均值不含筛选日 |
| 20日线上 | 收盘价 >包含筛选日的20日收盘均价 |
| 股性活跃 | 沿用冲高观察：最近20日 `(最高价−最低价)/前日收盘 ×100` 的均值 ≥5% |

“资金全红”在本策略中指3/5/10/20日四个主力累计窗口，不指超大单、大单、中单、小单同时流入。当日主力净额保留展示，不要求其单独大于0，也不以当日净额单独满足0.5亿元门槛；当日资金仍计入各累计窗口。“股性活跃”使用以上可复算口径。

## 入选后 T+1～T+5

在资金列后增加五列，与条件优选当前实现共用计算函数及单元格样式。每列上行显示最高累计涨幅，下行显示收盘累计涨幅。

- 收盘累计：`(第N个交易日收盘价 / 入选日收盘价 − 1) × 100`。
- 最高累计：`(第N个交易日当天最高价 / 入选日收盘价 − 1) × 100`，不是T+1到T+N期间最高值，也不是逐日涨跌幅相加。
- 使用本地交易日历，跳过周末和节假日。未来交易日没有收盘数据时显示“—”；历史日线缺失、不完整或相邻参考价偏差超过0.15个百分点时，该期及后续不计算，鼠标悬浮显示日期及原因。
- 盘中点击“刷新结果”，今日所在T列可显示“⚡最高/⚡实时”，同样以入选收盘价为基准；其余历史列取本地收盘日线。未来数据仅用于展示入选后表现，不参与入选筛选。
- 此口径以当前条件优选代码为准；条件优选旧文档中的算术相加说明尚未同步到当前实现。

## 数据与文件约定

- 筛选逻辑在 `backend/dip_picks.py`；注册入口在 `backend/app.py`；前端面板、独立请求和列表在 `dashboard/index.html`。
- 使用完整连续121个交易日日线；近20个交易日资金必须全部来自 `eastmoney-push2`，不混合其他来源、跳过缺日或将缺值填零。
- 日线须价格/成交量有效；相邻收盘计算涨跌幅与记录涨跌幅偏差超过0.15个百分点时，视为参考价异常，不计算120日涨幅。
- 只读 SQLite `mode=ro` + `query_only`，无新增数据库结构、快照、持久缓存或后台任务。
- 后端测试在 `backend/test_dip_picks.py`，前端测试在 `dashboard/test-dip-picks.cjs`；浏览器截图放系统临时目录，不进入项目。
