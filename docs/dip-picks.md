# 低吸选股

入口：选股推荐 → 东方财富 → 低吸选股。接口：`GET /api/picks/dip?date=YYYYMMDD`。

日期为空时使用最近可用收盘日；指定日期使用该交易日的收盘数据，不以最新大盘、资金或实时价替代历史数据。盘中等待收盘，必要行情或资金缺失时不入选。结果只表达条件匹配，不计算预测评分。

## 大盘触发条件

`下跌家数 > 2600 AND ((-1.6 < 上证涨跌幅 < 0 AND 非此前三日连涨) OR 上证涨跌幅 < -1.6)`。

- 下跌家数取同日 `overview.downCount`；上证涨跌幅取同日 `index_daily` 中“上证指数”的 `change`（百分数）。兼容数据库日期的 YYYYMMDD / YYYY-MM-DD 格式。
- 前三日是筛选日之前三个交易日，不包含筛选日；三日涨跌幅均 >0 才算连续上涨，平盘不算上涨。
- 恰好跌 −1.6% 不满足两条严格不等式；下跌家数恰好 2600、上证平盘或上涨也不触发。
- 上证跌幅超过 1.6% 时不需要前三日状态。未满足条件显示“不推荐”及原因；缺必要大盘数据则显示“数据不足”。[追高选股](dip-picks-v2.md)使用独立的大盘条件。

## 个股筛选条件

默认全部满足以下条件才入选，不从其他策略的名单二次过滤；关闭部分条件后，只要求已开启条件。

| 条件 | 计算公式 |
| --- | --- |
| 当日涨跌幅（可编辑） | 默认 `stock_daily.change < 0`；可修改比较方向及百分比 |
| 累计涨幅（可编辑，默认120日 <300%） | `(筛选日收盘 / 120个交易日前收盘 − 1) × 100 <300`；不是股价上限，也不是日涨跌幅的算术和 |
| 资金全红 | 东方财富 `main_net_inflow` 的最近3/5/10/20个交易日累计值全部 >0；各窗口包含筛选日 |
| 任一累计资金项 >0.5亿元 | 上述四个累计值中的最大值 >50,000,000元 |
| 5日均量小于1.2倍 | `筛选日成交量 / 此前5个交易日成交量均值 <1.2`，均值不含筛选日 |
| 20日线上 | 收盘价 >包含筛选日的20日收盘均价 |
| 股性活跃 | 沿用冲高观察：最近20日 `(最高价−最低价)/前日收盘 ×100` 的均值 ≥5% |

“资金全红”在本策略中指3/5/10/20日四个主力累计窗口，不指超大单、大单、中单、小单同时流入。当日主力净额保留展示，不要求其单独大于0，也不以当日净额单独满足0.5亿元门槛；当日资金仍计入各累计窗口。“股性活跃”使用以上可复算口径。

## 可编辑参数与均线多头（2026-10-07）

低吸的当日涨跌幅和累计涨幅支持四种比较：`lt`（<）、`le`（≤）、`gt`（>）、`ge`（≥）。默认当日<0%、120日累计<300%；累计周期可选1～250个交易日，N日累计为 `(入选收盘/N个交易日前收盘−1)×100`，需要连续N+1条有效日线。阈值为百分点，填写5即5%，只接受有限数值（绝对值≤1000000），非法参数返回400。严格边界使用1e-10百分点容差，名单、标签和诊断一致。

页面在两项条件下直接编辑周期、方向和百分比，点击“应用”后重筛。`tradeiq.dip.parameters.v1`独立保存参数，刷新、日期和策略切换保留；旧开关偏好继续沿用，追高不读取这些参数。“恢复全部开启”只恢复开关，保留自定义数值。损坏参数恢复默认，存储不可用提示当前页面有效。

新增默认开启的`bullish`条件：严格收盘>MA5>MA10>MA20>MA60，均线含筛选日，需要连续60条价格及参考核验有效日线。等值不通过，缺失不算符合。关闭后免除独有60日要求。保留原收盘>MA20独立开关（两者有重叠），名单补充显示MA5、MA10、MA60，累计涨幅列按当前周期显示。默认名单因此会比新增条件前更少；T+1～T+5计算方式不变。

名单`/api/picks/dip`、标签`/condition-counts`和诊断`/diagnostics`共同接受`return_days`、`return_op`、`return_threshold`、`change_op`、`change_threshold`。不传参数用默认值。计数缓存同时核对日期和参数，参数变化重新统计；旧名单、计数、诊断及市场温度响应不得覆盖新设置。筛选和计数只使用筛选日及此前数据，保持只读数据库连接，不新增表或任务。

## 条件开关、保存与数量标签

提供10项开关：`market_down`下跌家数>2600、`market_index`上证下跌及前三日走势、`decline`当日下跌、`return120`120日涨幅、`funds_red`资金全红、`funds_threshold`资金门槛、`volume`量比、`above_ma20`MA20、`amplitude`振幅、`bullish`均线多头。上证下跌、1.6%边界及前三日分支组成一个完整大盘条件；关闭下跌家数不放宽上证规则，反之亦然。

只读`GET /api/picks/dip?date=YYYYMMDD&disabled=条件键`；未知键返回400。关闭条件后免除其独有历史要求：当日下跌要求2日日线用于价格参考核验，累计N日涨幅N+1日，量比6日，MA20为20日，振幅21日，均线多头60日；资金任一条件开启仍要求完整20日同源资金，全部关闭允许缺资金入选但展示不补零。全部关闭仍要求当日日线有效、日期已收盘；不读取未来数据选股。默认全部开启使用当前完整规则，保留T+1～T+5口径。

浏览器键`tradeiq.dip.disabled.v1`持久保存关闭项，和追高的键完全独立。刷新、跨日期/Tab保留，恢复全部开启也保存；未知键忽略、损坏值回退默认，存储不可用时提示仅当前页面有效。重筛按策略、日期、配置及请求序号拦截旧响应，显示同日配置前后数量对比。

只读`GET /api/picks/dip/condition-counts?date=YYYYMMDD`返回10项独立的`matched/evaluated/missing/total`。按所选日期全市场收盘价>0的日线股票统计，每项只要求自身窗口，关闭条件也显示，不从最终名单或其他规则缩小统计范围。大盘单项满足时全市场均符合，否则为零；上证深跌分支不需要前三日数据。正数显示“N个符合”，零匹配显示“全军覆没”，无可评估数据显示“数据不足”，悬浮查看核验/缺失数量。统计不读未来、不补缺失，日期变化立即清空旧标签，同日开关复用统计，手动刷新重算。

## 未入选诊断

空名单显示“为什么没选出来”诊断：按当前开启条件，分别模拟只关闭一项后的入选数量；所有单项均为0时检查两项组合。大盘未通过、缺失、个股组合限制和必要数据缺失分别说明。诊断只用于条件对比，模拟不修改偏好。查看分页候选名单及差在哪一项，点击“应用此组合”才关闭对应项、保存并重筛。接口`/api/picks/dip/diagnostics`使用现有只读数据，支持`disabled`、`remove`（当前开启的1或2项）、`offset`和`limit`（默认50，上限100），未知或非法参数返回400；不读取未来行情或T+N。

## 市场温度

条件说明之后增加条件优选同款市场温度：上涨、下跌、平盘家数及比例条，上证指数、深证成指、创业板指、科创50分时。默认查看筛选日，左右箭头切换至本地日历中的T+1～T+5；仅改变市场背景查看日期，不重筛、不改变条件偏好及名单。空名单或大盘未触发时仍显示温度，并提供日历后续日期；同日刷新保留温度查看日，换策略或筛选日回到入选日。

复用`/api/conditional-picks/preferred/market-overview`与`/api/index/minline`，核验响应日期与请求日期完全一致；缺失、失败明确说明，不拿其他日期补齐。复用优选绘制函数，独立控件及图表实例，清除旧背景并拦截日期/策略/配置迟到响应。后续日期仅用于市场背景及T+N展示，不参与选股。

## 入选后 T+1～T+5

在资金列后增加五列，与条件优选当前实现共用计算函数及单元格样式。每列上行显示最高累计涨幅，下行显示收盘累计涨幅。

- 收盘累计：`(第N个交易日收盘价 / 入选日收盘价 − 1) × 100`。
- 最高累计：`(第N个交易日当天最高价 / 入选日收盘价 − 1) × 100`，不是T+1到T+N期间最高值，也不是逐日涨跌幅相加。
- 使用本地交易日历，跳过周末和节假日。未来交易日没有收盘数据时显示“—”；历史日线缺失、不完整或相邻参考价偏差超过0.15个百分点时，该期及后续不计算，鼠标悬浮显示日期及原因。
- 盘中点击“刷新结果”，今日所在T列可显示“⚡最高/⚡实时”，同样以入选收盘价为基准；其余历史列取本地收盘日线。未来数据仅用于展示入选后表现，不参与入选筛选。
- 此口径以当前条件优选代码为准；条件优选旧文档中的算术相加说明尚未同步到当前实现。

## 数据与文件约定

- 筛选逻辑在 `backend/dip_picks.py`；注册入口在 `backend/app.py`；前端面板、独立请求和列表在 `dashboard/index.html`。
- 默认全部开启时使用完整连续121个交易日日线；资金任一条件开启时近20个交易日资金须同源完整，不混合其他来源、跳过缺日或将缺值填零。关闭条件按上文缩短必要窗口。
- 日线须价格/成交量有效；相邻收盘计算涨跌幅与记录涨跌幅偏差超过0.15个百分点时，视为参考价异常，不计算120日涨幅。
- 只读 SQLite `mode=ro` + `query_only`，无新增数据库结构、快照、持久缓存或后台任务。
- 后端测试在 `backend/test_dip_picks.py`，前端测试在 `dashboard/test-dip-picks.cjs`；浏览器截图放系统临时目录，不进入项目。
