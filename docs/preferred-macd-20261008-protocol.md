# 条件优选与 MACD：历史关联研究协议

日期：2026-10-08。问题：条件优选入选后五交易日内最高涨幅严格大于 10% 的股票，入选日 MACD 有何共性？本研究不修改选股页面或规则，不把盘中最高价当作可实现净收益。

## 样本与标签

- 主样本来自本地 `conditional_picks_preferred_snapshot` 的实际保存名单。一个日期仅保存一套参数，不能据此声称覆盖全部参数的所有历史入选股票。按快照缩量参数（关闭、80%、99%）及实际成交量比分别列出结果。
- 用原始 `stock_daily` 重算标签，不使用快照中已保存的收益。入选日收盘为分母，五个后续本地交易日的最高价最大值为分子；严格 `>10%`。同时列第5日收盘收益，仅作区别，不扣交易成本、不假定收盘成交。
- 五日任一天缺记录、未收盘、无效 OHLC 或收盘变化与记录涨跌幅偏离超过 0.15 个百分点，整条标签待核验，不按失败或零收益计入。入选价须与同日日线一致。
- 对照组是同一条件优选名单中未超过10%的完整样本，不另换成全市场。逐笔保留排除原因。

## 入选日指标

- 常规日线 MACD(12,26,9)：EMA 递推权重 `2/(n+1)`，首个有效收盘初始化；DIF=EMA12−EMA26，DEA=EMA9(DIF)，柱=2×(DIF−DEA)。计算保留精度，展示再舍入。公式方向与当前个股图表一致；对跨股数值比较使用除以入选收盘价后的百分比。
- 仅取2025-04-01起的日线（此前市场历史覆盖不连续）。指标至少预热120根有效收盘。缺日后下一根必须核对参考价；价格不连续、无效价格或间隔超过10个本地交易日时重新初始化。这样不会将未复权断点直接当作动量。
- 同时计算不重置断点、按有效收盘连续递推的页面兼容版本，及60/150根预热敏感性分析。无复权因子，不能声称复权 MACD 已核验。
- 预先比较：DIF>0、DEA>0、双线零轴上/下、红柱/绿柱、当日金叉、近5日金叉/死叉、零轴上/下近5日金叉、红柱放大/缩短、绿柱缩短/放大、DIF当日/连续3日上升、DEA上升、金叉后5日内红柱、零轴上红柱缩短。金叉=当前DIF>DEA且前日DIF≤DEA；死叉相反。近5日包括入选日，所有状态只看入选日及此前。
- 不根据成功样本寻找最佳 MACD 参数或最佳阈值，不用未来确认的波峰波谷识别背离。连续指标列出成功/未成功组中位数，形态检验全部保留。

## 关联与稳定性

- 对每个形态列命中次数、超过10%次数、触及率、其余样本触及率、成功组/对照组覆盖、胜者召回率。样本少于20仅标为小样本线索。
- 同一批20种形态采用 Fisher 双侧检验与 Benjamini–Hochberg 多重比较修正。这一检验不假设能消除重复股票、市场阶段或其他因子的混杂。
- 对重点候选计算以入选日聚类的差值置信区间、按同期日期/缩量参数/板块分层的置换检验，并列4–6月与7–9月、各月和参数组。只要日期或股票重复，均不称事件独立。
- 聚类自助法的任一比较组少于20，或成功/未成功任一格少于5，不展示容易产生假确定性的置信区间；保留原始次数及精确检验。
- 去掉同一股票5个交易日内的重叠入选重复后复算；另列实际缩量≤80%的子样本和页面兼容算法结果。
- 月份、参数分布、样本较少、资金规则已筛选趋势等可能解释表面差异。仅在多个检查方向一致且样本充分时称相对稳定关联；结果即使显著也不等于因果关系或单笔平均净收益≥10%。
- 本次全部是已查看历史样本的探索研究，分期一致性检查不是独立样本外回测。

## 交付与验证

独立脚本、计算测试、报告、逐笔 CSV 与完整 JSON；数据库只读事务，不导入业务应用，不调用会写快照的接口。测试覆盖 EMA 数值、金叉时点、未来不改变入选指标、五交易日完整性、参考价断点、严格10%边界、重复样本处理、检验计算。抽查真实 SQL 对照与图表公式。
