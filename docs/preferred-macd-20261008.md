# 条件优选入选后的五日冲高，与 MACD 有什么关系？

2026-10-08；本地数据库截至2026-10-08收盘数据。分析入选日及此前的日线 MACD(12,26,9)，未来五交易日仅用于验证结果。不修改选股页面或规则。

## 结论

**最明显的共性是红柱，但它几乎没有区分能力。** 严格核验的75次超过10%记录中，71次为红柱（94.7%）；未超过10%的122次记录中，115次也为红柱（94.3%）。因此不能用“赢家大多是红柱”推导“红柱更容易成为赢家”。

**零轴下修复是可以继续观察的线索，尚未形成可靠选股条件。** 双线零轴下的触及率为47.1%，其余记录34.9%；近5日零轴下金叉为46.9%，其余36.4%。双线零轴下的方向在分期、去重和不同预热检查中仍为正，但样本较少、板块差异明显，置信区间跨0，统计检验未通过。若把双线零轴下设为必选，会保留24次成功，漏掉其余51次成功（68%）。

**当日金叉、红柱放大、红柱缩短、双线零轴上均没有获得稳定优势证明。** 20种预先定义形态的多重比较修正后，主样本最小q值0.958；同期日期/参数/板块分层置换也没有显著结果。部分分层能实际对照的记录很少，不能据此证明“MACD没有价值”；当前证据只能支持“这批条件优选名单中尚未证实可用增益”。

## 口径与样本

- 最高涨幅 = 未来第1至第5个本地交易日最高价中的最大值 / 入选日收盘价 − 1，严格大于10%。不是只看第5天，也不是逐日涨幅相加。
- 重算原始日线，不采信快照中的旧收益字段。当前程序已使用比值口径，旧规则文档仍有加总说明，本研究没有改动业务文档。
- MACD采用EMA12−EMA26为DIF、DIF的EMA9为DEA、2×(DIF−DEA)为柱。仅使用入选日及之前，跨股票的数值除以股价再比较。
- 首个有效收盘初始化。2025-04-01之前全市场覆盖不连续，不用于初始化；至少120根有效价格预热，参考价断点或长期缺日重新初始化。该方法保守地排除潜在未复权干扰，另列不重置断点的页面兼容版本。

## 对后续策略的含义

当前可以给候选加“零轴下修复/近期金叉”的研究标签；证据不足以将其设成必选条件或承诺提高收益。普通红柱、单日金叉没有显示可用增益。若后续继续开发，需控制板块、波动和市场阶段，将MACD候选与原规则比较，并使用真正未看过的数据验证可成交收益。

主分析的第5日收盘价格收益平均仅+0.10%，页面兼容完整样本为+1.15%，均未扣成本、也未使用次日可成交买价；不能用这些触及结果满足此前“单笔平均净收益至少10%”的验收条件。
