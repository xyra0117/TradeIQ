# T+5 策略研究协议（先于收益搜索冻结）

用户目标：单笔平均净收益至少10%，历史回测支撑；不接入前端。正式验收仍由用户决定。

1. D收盘产生信号，D+1开盘模拟买入，D+5收盘计划卖出；T从信号日算起。不得以D收盘或未来最高价替代可执行收益。
2. 全部本地表先审计。日线、可追溯个股资金、同日指数及历史涨停题材供研究；当前成分/股本/市值、单日两融、空表、稀疏分钟与个人交易配置不硬塞进历史指标。两融市场总量若用则至少滞后2个交易日。历史名称与退市样本完整性不足需披露。
3. 数据库只读，不获取新行情，不安装依赖。日线成交额千元换元；资金合并已存的两类东财来源，不混合同花顺口径。历史窗口必须连续，价格参考偏差超过0.15个百分点不使用该历史窗口。不使用当前ST身份反向剔除过去股票。
4. 次日开盘触涨停不成交；涨幅限制根据当日已有名称/板块及历史规则计算，未知身份保守处理。可预设次日高开上限；不能根据买入后的行情决定是否买入。计划卖出日收盘跌停或无报价则延期，最多跟踪20日。未来除权参考异常或无法退出保留为不可核验，不悄悄删除。
5. 买卖双边佣金各0.03%，各最低5元；过户费双边各0.001%，卖出印花税0.05%；基础滑点双边各0.1%，压力情形双边各0.3%/0.5%。这是明确的模拟费率，具体账户佣金可后续替换。日线不能证明开收盘队列成交。
6. 100万元固定初始资金，每天最多投入前一日净值20%，单股最多10%，按候选TopK等分，无杠杆、不重复持有同股、不能从未来可成交性倒推补选。资金不足不买；交易额不超过信号日成交额0.1%。每日先开盘买入，再收盘卖出，避免使用尚未结算的当日收盘收入在当天开盘买入。
7. 主结果固定T+5退出，不用日线内先后不明的止盈止损提高收益。比较趋势突破、强势回调、超跌反转、首板/连板延续、动量资金等有限粗网格；先开发、再验证、最后冻结。收益均为模型模拟，不能保证未来实盘。
8. 技术策略开发：2025-07—2026-03；验证：2026-04—06。资金策略因覆盖短，开发：2026-04—05；验证：2026-06。每段仅纳入计划退出在该段末日前的信号，延期退出也不得向后段借结果。最终保留2026-07—09，只在参数冻结后查看。各段间不共享未到期标签。
9. 暂定研究可信度门槛：样本外至少100笔实际执行且可核验交易、至少30个信号日、覆盖3个月，平均净收益≥10%，5日日期块bootstrap下沿>0。组合最大回撤20%作为参考风险目标单列，不替代用户收益目标。缺失交易以-30%收益做敏感性边界，但这不是真实缺失收益；不可核验交易未解决时不标正式通过。
10. 报告均值、中位数、胜率、≥10%交易比例、最差交易、月份、基准超额、组合净值/回撤/仓位、未成交及不可核验数量、去极端赢家与成本压力。失败及所有尝试保留；测试期失败后该期变为已查看验证，后续需新的未查看数据。

开发阶段补充：两轮阈值组合没有达到10%，在查看最终保留期前增加第三轮。只增加可追溯的市场资金、四指数一致性、申万时点行业相对强度与已披露题材资金；资料与限制写入同前缀的 `feature-audit.json`。另比较带L2约束的线性指标排序模型，截断、标准化、权重均仅用开发段拟合，训练标签必须在开发段内到期，测试不重新拟合。第三轮仍采用同一交易口径与质量规则，不改变验收门槛。

官方规则依据：上海证券交易所《交易规则（2026年修订）》https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml；财政部、税务总局2023年第39号公告 https://tianjin.chinatax.gov.cn/11200000000/0300/030004/03000418/20230828081811621.shtml。过户费作为保守模型假设列明，不以未核实费率精确度证明策略收益。
