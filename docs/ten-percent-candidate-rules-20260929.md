# 10日冲高观察池：候选筛选标准 v0.1

日期：2026-09-29。目标为未来10个交易日内最高价相对筛选日收盘价上涨超过10%。这是研究观察池，尚未形成可交易的买入、卖出策略；不修改现有应用规则。

## 三项必选条件

1. 最近20个交易日平均振幅≥5%。日振幅为（最高价−最低价）÷前日收盘价，取20日算术平均。
2. 筛选日收盘价高于MA20，即最近20个交易日（含筛选日）收盘价的平均值。
3. 下列满足其一：筛选日收盘价相对20个交易日前收盘价涨幅>15%；或筛选日收盘价高于此前20个交易日（不含筛选日）的最高价。

使用完整收盘数据，不用盘中未完成的日线套用本次比例。计算相关历史窗口须连续、字段有效，价格参考异常时不强行拼接。任一必选特征缺失则不判为入选。

## 辅助标签

最近5个完整交易日主力净流入合计÷同期成交额合计≥5%，可以附加资金标签，但不设为全历史必选条件。资金来源保持一致，净额单位元，数据库成交额千元需乘1000；缺失标记为缺数据，不按零计算。

同一资金覆盖子样本中，核心观察池19,922条观察，10日触及比例34.81%；加资金条件后2,927条、39.63%。这仅覆盖59个起点日期，不能与核心全时段45.61%直接比较。

不强制放量≥前5日均量1.5倍：叠加后触及比例只从45.61%升到46.43%，到期收盘涨幅中位数由−2.63%降至−3.56%。温和缩量、当日小单流出也不列为硬条件。

2026-04以前与之后，核心组10日触及比例为45.46%与45.86%；同股预先去除未来窗口重叠后的子样本为10,526条、46.07%；主板内部48,043条、44.26%。这些是方向检查，不是独立样本外验证。资金覆盖子时期的核心比例仅34.81%，仍有阶段差异。

同时比较了：全市场、高振幅、核心、高振幅核心加放量、核心加资金、核心加放量与资金。没有继续搜寻更多门槛来追求更好看的结果。阈值来自前一轮已观察的数据，存在研究选择偏差；未作多重检验校正。

观察池筛选用到当日收盘、全天最高价和成交量，不能假定盘中已知这些条件。以上以当日收盘作为衡量基准，没有模拟次日可成交价格、涨停无法买入、交易费用或退出规则。

期间最低价可能发生在冲高之前或之后，不能从汇总数据推断止盈止损顺序。既然收盘表现并不理想，当前不能将这套标准称为已验证的赚钱策略。

后续若验证可交易策略，需要先固定次日入场、退出和成本规则，再用未参与选规则的数据检验。历史表现不保证未来结果，参考 [SEC投资者教育：业绩展示的解释边界](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-47)。
